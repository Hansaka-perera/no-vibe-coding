# Quick Notes - Learning Version

No database. No Supabase. No PostgreSQL. No Python backend.

Tech:
- HTML
- CSS
- TypeScript
- browser localStorage

Run:
1. Open this folder in VS Code.
2. Run `npm install`
3. Run `npm run build`
4. Open `index.html`

Learn:
- interfaces
- variables and arrays
- functions
- DOM
- events
- forEach
- filter
- localStorage
- JSON.stringify / JSON.parse
